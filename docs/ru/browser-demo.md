# Демо в браузере

[Откройте демо](https://lyova24.github.io/quite-admin/demo/), используйте `admin` / `admin`.
Workflow документации собирает и публикует его по пути `/demo/`.

Откройте запись по строке, измените поле и связь, сохраните на той же странице.
Customers/profiles показывают 1:1, customers/orders — 1:N, products/tags — M:N.
Доступны поиск, сортировка, фильтры списков, поиск связанных записей, пагинация,
создание, подтверждение удаления, EN/RU, [интерактивная схема БД](database-schema.md) и отчёт.
Изменения хранятся в браузере, если разрешён localStorage. Сброс восстанавливает
фиктивные данные; у каждого посетителя собственная копия.

Это самостоятельная JavaScript-демонстрация интерфейса. Схема и начальные данные
экспортируются из адаптера настоящего примера, CSS копируется из Python-пакета.
В браузере работает небольшой транзакционный store для фиксированной демо-схемы.
FastAPI, Litestar, ORM и сервер авторизации там не запускаются; это не проверка
серверных прав или совместимости БД. Production-авторизация и CSP остаются в ASGI.
Настоящие cookies, пароли, production-секреты и записи приложения не экспортируются.

Настоящее ASGI-приложение запускается через [локальный пример](quickstart.md).
Сборщик статического демо всегда создаёт временную SQLite-базу и случайные временные
учётные данные, не подключаясь к базе пользовательского приложения.

## Локальная сборка

```bash
uv sync --locked
npm ci
npm run docs:build
npm run demo:test
npm run docs:serve
```

Откройте [localhost:8001/demo/](http://localhost:8001/demo/). В `build/docs/demo`
находятся HTML, скрипты, JSON и CSS. Hash-навигация работает под префиксом репозитория
без серверного route fallback. Node-тесты проверяют обе стороны связей, rollback
при обязательной связи, замену 1:1, создание и удаление. Весь результат включается
в существующий артефакт публикации сайта.
