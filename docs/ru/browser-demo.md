# Демо в браузере

[Откройте демо](https://lyova24.github.io/quite-admin/demo/), используйте `admin` / `admin`.
Workflow документации собирает и публикует его по пути `/demo/`.
На главной появились ссылки **Знакомство с интерфейсом** на новые примеры.
[Обзор интерфейса](interface-tour.md) содержит скриншоты и пошаговые сценарии.

## Что попробовать

| Экран | Работающий пример |
| --- | --- |
| Products | Измените цену/остаток прямо в ячейке, сохраните или отмените; переключите Active в списке |
| Schedules | DATE, DATETIME с микросекундами, nullable TIME, boolean с состоянием NULL, многострочный TEXT и JSON с подсветкой |
| История действий | Примеры событий двух вымышленных пользователей и ваши локальные действия, сравнения «было → стало», Журнал/Таблица, общие фильтры и выбор дня/диапазона UTC |
| Фильтры списков | Фрагменты текста, повторные условия, диапазоны чисел/дат, наборы, SQL NULL, пустой текст и связанные записи; редактирование чипов |
| Orders | Переходы Далее/Назад в стиле cursor pagination, сортировка по первичному ключу, без точного общего количества |
| Экспорт данных | Выбор скалярных столбцов и CSV всех подходящих записей, включая другие страницы |
| Customers / Customer Profiles / Orders | Редакторы связей 1:1 и 1:N с поиском и атомарным локальным сохранением |
| Products / Tags | Редакторы M:N с поиском; конкурентные изменения форм вызывают конфликт устаревшего сохранения |
| Боковая панель / Схема БД | Сворачиваемые группы с запоминанием, видимость таблиц, раскрытие полей, промежуточные таблицы M:N, перетаскивание и автокомпоновка |
| Store report | Пользовательская страница на основе локальных демоданных |

Переключите **Language**, чтобы проверить английские и русские контролы. Изменения и
последние 200 локальных событий сохраняются в браузере, если разрешён localStorage.
**Сбросить демо** восстанавливает записи и примеры истории. У каждого посетителя своя копия.
Старые сохранённые демо получают новые коллекции и метаданные полей без потери локальных записей.

## Что показывает браузер, а что требует сервера

Это самостоятельная JavaScript-демонстрация. Схема, вымышленные данные, правила полей
и разметка периода экспортируются из адаптера/шаблонов настоящего примера.
CSS и компоненты дат, форм, JSON, boolean, редактирования ячеек, фильтров, связей и схемы
берутся из Python-пакета. В JavaScript реализованы store фиксированной демо-схемы и его транспорт запросов.

| Доступно в браузерном демо | Требует настоящего ASGI-приложения |
| --- | --- |
| Локальная история «было → стало», фильтры пользователя/дат и оба вида | Постоянное хранилище SQLite/PostgreSQL/MySQL, таблицы `quiteadmin_`, автоинициализация, права/скрытие чувствительных данных и `history_enabled` |
| Переходы в стиле cursor pagination по вымышленным записям | Keyset-запросы БД без COUNT/OFFSET и подписанные курсоры со сроком действия |
| Скалярный CSV с выбором столбцов, текущими фильтрами и сортировкой | XLSX, связанные столбцы, пакетные запросы связей и серверные ограничения экспорта |
| Локальная валидация, откат связей и защита от устаревших сохранений | Авторизация, CSRF, права, атомарные записи БД, хуки/действия и таймауты SQL-чтения |

В браузере не запускаются FastAPI, Litestar, ORM и сервер авторизации. Вход
`admin` / `admin` — пример интерфейса. Он не проверяет серверную безопасность,
надёжность аудита или совместимость БД. Настоящие cookies, пароли, production-секреты
и записи приложения не экспортируются.

Для этих возможностей запустите [локальный ASGI-пример](quickstart.md).
В нём есть те же поля Schedules, группы и cursor-режим Orders, а также настоящее
хранилище истории и CSV/XLSX. Настройка и гарантии описаны в разделах
[хранилища](storage.md), [конфигурации](configuration.md) и [экспорта](exports.md).
Редактор raw SQL и конструктор дашбордов пока не реализованы.

## Локальная сборка

```bash
uv sync --locked
npm ci
npm run docs:build
npm run demo:test
npm run docs:serve
```

Откройте [localhost:8001/demo/](http://localhost:8001/demo/). Сборщик всегда создаёт
временную SQLite-базу и случайные временные учётные данные, не подключаясь к БД
пользовательского приложения. Результат находится в `build/docs/demo`; hash-навигация
работает с префиксом репозитория без серверного fallback. После сборки документации
пересоберите демо: документация заменяет выходную директорию.

Node-тесты проверяют связи/откат, устаревшие сохранения, сохранение истории и включительные
даты, обновление демоданных, окна пагинации, CSV-экранирование, фильтры и компоновку схемы.
Весь результат входит в существующий артефакт публикации сайта.
