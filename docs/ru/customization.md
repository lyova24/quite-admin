# Язык и оформление

Настройки задаются при создании каждого экземпляра админки. API одинаков для FastAPI и Litestar:

```python
from quite_admin import Admin, Theme

admin = Admin(
    auth=auth_backend,
    secret_key=session_secret,
    title="Управление магазином",
    description="Товары, клиенты и заказы в одном месте.",
    language="ru",
    logo="assets/logo.svg",
    theme=Theme(
        primary="#2563eb",
        background="#f8fafc",
        surface="#ffffff",
        text="#0f172a",
        muted="#64748b",
        border="#e2e8f0",
        danger="#dc2626",
        on_primary="#ffffff",
        on_danger="#ffffff",
    ),
)
```

Все настройки необязательны. По умолчанию используются `title="Quite Admin"`,
`description=""`, `language="en"` и исходная светлая тема с зелёным акцентом.

## Язык

`language="en"` включает английский, `language="ru"` — русский. Другие значения вызывают `ValueError`.
Переведены все встроенные экраны: вход, навигация, действия CRUD, пустые состояния,
пагинация, подписи логических значений, ошибки валидации и стандартные сообщения библиотеки.
Счётчики записей, коллекций и полей учитывают русские формы множественного числа.
Атрибут HTML `lang` соответствует выбранному языку.

Язык выбирается в конфигурации приложения. Автоматического определения по браузеру,
настроек языка пользователя и встроенного переключателя нет.
Несколько экземпляров админки в одном приложении могут иметь разные языки и темы.
При их размещении на одном хосте задавайте разные имена `session_cookie`.

Названия моделей и полей, подсказки, варианты enum, ошибки собственных адаптеров,
тексты своих страниц и значения записей задаёт приложение. Они не переводятся автоматически.
Для подписей используйте `ModelOptions(label=...)` и `FieldOptions(label=..., help_text=...)`.
Переводятся только известные сообщения библиотеки; неизвестные ошибки показываются как переданы.
В формы по-прежнему отправляются `true` / `false`. Данные, URL и имена событий логирования не меняются.

## Название и описание

`title` задаёт имя админки в заголовке браузера, боковом меню и основном заголовке
страниц входа и обзора. Внизу бокового меню остаётся название библиотеки Quite Admin.

`description` — обычный текст под названием на страницах входа и обзора.
Он также попадает в HTML-метаданные описания. Если описание пустое, страницы
не показывают вступление, а meta-тег description не добавляется.
Название и описание экранируются как текст и не поддерживают HTML.

`logo` — путь к существующему локальному SVG, PNG, JPEG, WebP или GIF.
Относительные пути вычисляются от рабочего каталога приложения. Изображение доступно по
маршруту `/logo` с учётом mount/proxy и показывается в боковом меню и на странице входа.
По умолчанию используется знак `q.`. Отсутствующий файл или неподдерживаемое расширение вызывают
`ValueError`. Свои шаблоны получают `logo_url`; внешние хосты и изменение CSP не нужны.
Встроенные экраны не содержат рекламных слоганов.

## Цвета

`Theme` принимает цвета в шестнадцатеричном формате `#RGB` или `#RRGGBB` в любом регистре.
Некорректное значение вызывает `ValueError` при создании темы.

| Параметр | По умолчанию | Применение |
| --- | --- | --- |
| `primary` | `#3e6656` | Основные кнопки, акценты навигации, иконки и положительные статусы |
| `background` | `#f7f8fa` | Основной фон страниц |
| `surface` | `#ffffff` | Боковое меню, шапка, карточки, поля ввода и панели |
| `text` | `#1c2635` | Основной текст |
| `muted` | `#7b8594` | Вторичный текст и подсказки |
| `border` | `#e9ecf1` | Рамки и разделители |
| `danger` | `#ba4949` | Удаление и ошибки |
| `on_primary` | `#ffffff` | Текст основных кнопок и знак в названии |
| `on_danger` | `#ffffff` | Текст кнопок удаления |

Цвета наведения и тонированные фоны вычисляются из палитры. Подбирайте читаемые сочетания
текста и фона, в том числе `on_primary` и `on_danger`. Пример тёмной палитры:

```python
theme = Theme(
    primary="#93c5fd",
    background="#0f172a",
    surface="#172033",
    text="#e2e8f0",
    muted="#94a3b8",
    border="#334155",
    danger="#fca5a5",
    on_primary="#0f172a",
    on_danger="#450a0a",
)
```

Тема загружается с собственного маршрута админки `/theme.css` после основного CSS.
Префиксы монтирования и reverse proxy учитываются автоматически.
Встроенные стили, внешний CDN и JavaScript не нужны; политика `style-src 'self'` сохраняется.

## Свои шаблоны

Шаблоны, наследующие `quite_admin/base.html`, получают выбранные название, язык и цвета.
В общем контексте доступны `title`, `description`, `language`, `theme`, `t` и `tn`:

```html
{% extends "quite_admin/base.html" %}
{% block content %}
  <h1>{{ 'Отчёты' if language == 'ru' else 'Reports' }}</h1>
  <p>{{ t('Save changes') }}</p>
  <p>{{ total }} {{ tn('record', 'records', total) }}</p>
{% endblock %}
```

`t(message, **values)` и `tn(singular, plural, count)` используют встроенный словарь.
Для своих текстов нужен перевод приложения, как в заголовке выше.
В Python те же функции доступны через `admin.gettext(...)` и `admin.ngettext(...)`.

В собственном CSS с того же origin используйте `var(--accent)`, `var(--paper)`, `var(--text)`,
`var(--muted)`, `var(--line)` и `var(--danger)`, чтобы соблюдать выбранную палитру.
Регистрация описана в разделе [своих страниц и шаблонов](custom-pages.md).
